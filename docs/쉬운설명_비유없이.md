# 시뮬레이션 1~4차 설명 (비유 없이, 쉬운 말로)

## 1. 무엇을 알아보려 했나

부산 신항에는 7개 터미널(부두)이 있고, 각 터미널은 자기 선석(배가 접안하는 자리)만 사용합니다. 컨테이너선이 들어와 컨테이너를 내리면, 이 가운데 일부(환적 컨테이너)는 야드(컨테이너 장치장)에 보관되었다가 다른 배(연결선)에 실려 나갑니다. 환적 컨테이너가 야드에 머무는 시간을 **야드 체류시간**이라 하며, 2025년 평균은 약 227시간(약 9.5일)입니다.

알아보려 한 질문은 두 가지입니다.

1. 터미널들이 선석을 함께 쓰면 배의 접안 대기와 야드 체류시간이 줄어드는가?
2. 줄어든다면 어떤 방법으로 얼마나(목표 1·3·5·10·15·20·25·30%) 줄일 수 있는가?

## 2. 시뮬레이션이란

2025년에 실제로 있었던 7,041건의 접안 기록을 컴퓨터에 입력하고, 선석 사용 규칙을 바꿔 다시 배정해 보는 계산입니다. 규칙만 바꾸고 나머지는 같게 두므로, 결과 차이는 규칙 변경의 효과로 볼 수 있습니다. 실제 항만을 바꾸지 않고 미리 비교할 수 있다는 점이 장점입니다.

세 가지 규칙(시나리오)을 비교했습니다.

| 시나리오 | 내용 |
|---|---|
| A (기존) | 각 터미널이 자기 선석만 사용 |
| B (인접 공유) | 이웃한 터미널끼리만 선석 공유 |
| C (전체 통합) | 7개 터미널이 모든 선석 공유 |

## 3. 차수별 설명

### 1차: A와 C 비교

- **방법:** 같은 입력으로 A와 C를 계산했습니다.
- **결과:** 평균 접안 대기는 0.93시간에서 0.00시간으로 줄었습니다. 반면 환적 컨테이너의 평균 야드 체류시간은 거의 변하지 않았습니다(변화 폭 −0.71~+1.08시간, 기존의 ±0.6% 이내).
- **의미:** 선석 통합은 배의 대기를 줄이지만, 컨테이너의 야드 체류시간을 줄이지는 못했습니다.

### 2차: B 추가, 검증, 원인 분석

- **방법:** 시나리오 B를 추가하고, 모델이 실제와 얼마나 맞는지 검증하고, 야드 체류시간이 무엇으로 결정되는지 분석했습니다.
- **결과 1:** B는 C가 줄이는 평균 대기의 약 93~96%를 줄였습니다. 이웃 관계를 무작위로 바꿔 30번 시험해도 B의 평균 대기는 0.051~0.075시간으로 거의 같았습니다.
- **결과 2:** 야드 체류시간과 "연결선 접안 시각 − 모선 접안 시각"의 상관계수는 0.999였습니다. 체류시간은 선석 혼잡이 아니라 두 배의 접안 시각 차이(연결선 간격)로 거의 정해집니다.
- **결과 3:** 모선을 일부러 묘박지(항구 밖 대기 구역)에서 더 기다리게 하면 야드 체류시간은 줄지만(24시간 상한 기준 18.7시간), 컨테이너의 총 체류시간은 그대로이고 선박 대기가 그만큼 늘어납니다(약 2.4만 선박·시간). 비용이 선박으로 옮겨질 뿐입니다.
- **검증:** 실제 접안 시각을 0.5시간 이내로 맞힌 비율은 82.4%입니다. 다만 실제 박지 대기 시간(평균 36.4시간)은 모델이 2.2%만 설명합니다.
- **의미:** 야드 체류시간을 줄이려면 연결선 간격을 줄여야 합니다. 선석 통합은 접안 대기 완화용입니다.

### 3차: 목표 감소율과 연결선 앞당김

- **방법:** 연결선을 a시간 일찍 도착시키는 규칙을 시뮬레이션에 넣고, 선석 배정을 다시 계산했습니다. 앞당긴 뒤에도 연결선 간격이 최소 24시간은 남도록 제한했습니다.
- **결과 1:** 2차에서 산식으로만 계산한 "24시간 앞당기면 약 10% 감소"는 실제 시뮬레이션에서 달랐습니다. 24시간 앞당김의 감소율은 모든 배를 앞당길 때 3.1%였습니다.
- **원인 1:** 한 배가 연결선이면서 동시에 모선이기도 합니다. 그 배를 일찍 오게 하면 배에 싣는 컨테이너의 체류는 줄지만, 그 배에서 내리는 컨테이너는 다음 배와의 간격이 늘어 체류가 길어집니다.
- **원인 2:** 일찍 도착한 배가 자리를 차지해 다른 선박의 접안이 늦어질 수 있습니다.
- **개선:** 싣는 컨테이너가 내리는 컨테이너보다 많은 배만 앞당기는 "선별 앞당김"을 만들었습니다.

| 요청 앞당김 | 모든 배 앞당김 | 선별 앞당김 |
|---|---|---|
| 24시간 | 3.1% | 5.6% |
| 48시간 | 5.9% | 10.5% |

- **목표별 필요 앞당김(선별, 시나리오 A):** 1%에 4.5시간, 3%에 14.3시간, 5%에 21.8시간, 10%에 45.3시간, 15%에 81.2시간, 20%에 145.9시간이 필요합니다. 25%와 30%는 최소 간격 24시간 조건에서 도달하지 못합니다(최대 24.3%).
- **통합의 역할:** 야드 체류 감소율은 A, B, C가 거의 같습니다. 차이는 부작용입니다. 앞당기지 않은 선박의 평균 접안 지연은 48시간 앞당김에서 A 0.23시간, B 0.04시간, C 0.01시간입니다. 통합과 인접 공유는 체류시간을 줄이지 않지만, 앞당김으로 생기는 선석 충돌을 줄입니다.

### 4차: 불확실성 구간과 하반기 검증

- **방법 1:** 선박 길이를 무작위로 채우는 과정을 100번 반복하고, 결과의 95% 구간을 구했습니다. 구간은 (가) 반복 간 범위와 (나) 연결선(배) 단위로 데이터를 다시 뽑는 부트스트랩 방식으로 계산했습니다.
- **결과 1:** 반복 간 변동은 ±0.1%p 이내로 작습니다. 그러나 어떤 연결선이 데이터에 포함되는지에 따른 불확실성은 큽니다.

| 선별 앞당김 | 감소율 | 95% 구간 |
|---|---|---|
| 24시간 | 5.6% | 4.3~7.0% |
| 48시간 | 10.5% | 8.0~13.1% |
| 96시간 | 16.8% | 12.9~20.7% |
| 168시간 | 21.4% | 16.5~26.3% |

- **보수적 판정:** 구간의 하한을 기준으로 하면 확실히 달성하는 목표는 24시간에서 3%, 48시간에서 5%, 72~96시간에서 10%, 168시간에서 15%입니다.
- **방법 2:** 1~6월(상반기) 데이터로 규칙을 만들고, 7~12월(하반기) 데이터로 시험했습니다.
- **결과 2:** 선별 앞당김은 하반기에서도 모든 배를 앞당기는 방법의 약 2배 효과를 냈습니다(48시간, 시나리오 A: 9.3% 대 4.7%). 후보 425척 중 25%(106척)만 앞당겨도 선별 효과의 73%를 얻었습니다. 무작위로 25%를 고르면 2.2%입니다.
- **결과 3:** 앞당김이 실제로 실현되는 비율을 예측하는 모형을 상반기로 학습했으나 하반기 설명력(R²)이 0.08로 낮았고, 이를 순위에 반영해도 단순 규칙과 차이가 0.06%p 이내였습니다. 단순 규칙(싣는 컨테이너 − 내리는 컨테이너)을 유지합니다.

## 4. 전체 결론

1. 환적 컨테이너의 야드 체류시간은 선석 부족이 아니라 연결선 간격으로 결정됩니다.
2. 선석 통합(B, C)은 접안 대기를 줄이지만 야드 체류시간은 줄이지 못합니다.
3. 체류시간은 연결선을 앞당겨 줄이며, 싣는 컨테이너가 많은 배부터 앞당기는 것이 효율적입니다. 최소 간격 24시간 조건에서 목표 20%까지는 가능하고 25% 이상은 어렵습니다.
4. 통합과 인접 공유는 앞당김이 만드는 다른 선박의 접안 지연을 줄이는 역할을 합니다.

## 5. 한계

- 연결선을 실제로 일찍 오게 할 수 있는지는 확인하지 못했습니다. 연결선이 다른 항구에서 화물을 싣는 시각과 선사 운항 계획 자료가 없습니다.
- 최소 연결 간격 24시간은 가정입니다. 실제 최소 환적 처리 시간으로 바꾸면 결과가 달라집니다.
- 선박의 실제 도착 시각 자료가 없어 박지 대기를 거의 설명하지 못합니다(설명 비율 2.2%).
- 상반기와 하반기는 같은 해의 두 구간이라 계절과 연도 차이는 검증하지 못했습니다.
- 모든 수치는 2025년 데이터 기준이며, 절대값보다 시나리오 간 상대 비교로 읽어야 합니다.

## 6. 용어

| 용어 | 뜻 |
|---|---|
| 환적 | 컨테이너를 한 배에서 내려 다른 배로 옮겨 싣는 것 |
| 야드 체류시간 | 환적 컨테이너가 야드에 머무는 시간 |
| 모선 | 컨테이너를 처음 싣고 온 배 |
| 연결선 | 환적 컨테이너를 다음 목적지로 실어 가는 배 |
| 연결선 간격 | 연결선 접안 시각 − 모선 접안 시각 |
| 선석 | 배가 접안하는 안벽의 자리 |
| 묘박지 | 접안 전에 배가 항구 밖에서 대기하는 구역 |
| 앞당김 | 연결선을 계획보다 일찍 도착시키는 것 |
| 선별 앞당김 | 싣는 컨테이너가 내리는 컨테이너보다 많은 배만 앞당기는 방법 |
| 95% 구간 | 데이터를 여러 번 다시 뽑아 계산했을 때 결과의 95%가 들어가는 범위 |
| KPI | 성과를 재는 지표(여기서는 평균 야드 체류시간 감소율) |
