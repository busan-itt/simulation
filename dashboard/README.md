# 부산 신항 환적 야드 체류 개선 시뮬레이션 대시보드

`최종 시뮬레이션.ipynb`의 결과를 보여주는 Streamlit 대시보드입니다. 앱 안에서 시뮬레이션을 다시 돌리지 않고, `data/`의 결과표를 읽습니다.

## 실행

```bash
cd dashboard
pip install -r requirements.txt
streamlit run app.py
```

## 화면 구성

| 탭 | 내용 |
|---|---|
| ① 요약 | KPI 카드, 최종 결과표, 핵심 메시지, 개선 순서 |
| ② 연결선 조정 시뮬레이터 | 조정 방식(선별/전체), 선석 운영(A/B/C), 요청 앞당김 선택 → 체류 감소율과 95% 구간, 목표 감소율별 필요 앞당김 |
| ③ A/B/C 선석 운영의 역할 | 감소율, 다른 선박 접안 지연, 조정 실현율 비교 |
| ④ 우선 조정 연결선 | 기대 이득 순 연결선 목록(터미널 필터, 상위 N, CSV 내려받기), 누적 이득 곡선 |
| ⑤ 검증·근거 | 간격-체류 관계, 모델 검증(36.4h vs 0.8h), 불확실성, 하반기 검증, 민감도, ML 보완 |
| ⑥ 한계와 결론 | 증명한 것 / 증명하지 못한 것 / 한계 |

## 데이터 갱신

`최종 시뮬레이션.ipynb`를 끝까지 실행하면 마지막 셀이 `output/dashboard/`에 결과표를 저장합니다. 그 파일들을 `dashboard/data/`로 복사하면 대시보드가 새 결과로 바뀝니다.

## 배포 (Streamlit Community Cloud)

저장소를 연결하고 Main file path를 `dashboard/app.py`로 지정합니다. 의존성은 `dashboard/requirements.txt`를 사용합니다.

## 주의

모든 수치는 2025년 데이터 기준의 시뮬레이션 결과이며, 선박의 실제 지연 전체를 예측하지 않습니다. 실제 적용 효과를 보장하지 않습니다.
