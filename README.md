# 부산 신항 선석 통합운영 시뮬레이션

**부산 신항의 선석 통합운영을 통한 환적 체류시간 저감** 프로젝트의 시뮬레이션 저장소입니다.

2025년 부산 신항 7개 터미널의 자료를 바탕으로 선석 통합운영과 연결선 일정 조정이 접안 대기 및 환적 야드 체류시간에 미치는 영향을 비교합니다.

[최종 시뮬레이션](<최종 시뮬레이션.ipynb>) · [1~6차 시뮬레이션](simulation/) · [사용 데이터](<시뮬레이션 사용 데이터/>)

## 최종 시뮬레이션

먼저 **[최종 시뮬레이션.ipynb](<최종 시뮬레이션.ipynb>)**를 확인해 주세요.

- **운영 시나리오:** A 기존 터미널별 운영 / B 인접 터미널 공유 / C 신항 전체 통합
- **주요 비교 지표:** 평균 야드 체류시간, 야드 체류 감소율, 다른 선박의 평균 접안 지연, 요청 대비 일정 조정 실현율
- **검증:** 반복 시뮬레이션, 불확실성 구간, 상·하반기 분리 검증 및 머신러닝 입력 보완

최종본은 4차의 검증 구조와 6차의 머신러닝 입력 보완 일부를 바탕으로 정리했습니다. 5차의 외부 평균 대기시간 보정은 최종 결론에 사용하지 않았습니다.

## 1~6차 시뮬레이션

| 차수 | 노트북 | 주요 내용 |
| :--- | :--- | :--- |
| 1차 | [simulation.ipynb](simulation/simulation.ipynb) | 기존 운영과 전체 통합운영 비교 |
| 2차 | [simulation_v2.ipynb](simulation/simulation_v2.ipynb) | A/B/C 비교, PORT-MIS 입항 시각 반영, 모델 검증 및 민감도 분석 |
| 3차 | [simulation_v3.ipynb](simulation/simulation_v3.ipynb) | 연결선 단위 일정 앞당김과 체류시간 감소 목표 검토 |
| 4차 | [simulation_v4.ipynb](simulation/simulation_v4.ipynb) | 반복 실험, 불확실성 구간 및 하반기 검증 |
| 5차 | [simulation_v5.ipynb](simulation/simulation_v5.ipynb) | 외부 평균 대기시간 8.7시간을 기준으로 한 보정 실험 |
| 6차 | [simulation_v6.ipynb](simulation/simulation_v6.ipynb) | 머신러닝 기반 선석 점유시간·선박 길이 예측을 입력에 반영 |

각 차수는 서로 다른 조건과 가정을 사용한 실험 기록입니다. 최종 해석은 최종 노트북의 조건과 한계를 기준으로 확인해 주세요.
