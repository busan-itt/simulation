# 부산 신항 선석 통합운영 시뮬레이션 (2025)

2025년 부산 신항 7개 터미널의 실제 접안 실적을 다시 배정해 선석 통합운영(B 인접공유, C 전체통합)이 접안 대기와 환적 야드 체류에 주는 효과를 비교한다.

## 결과 리포트
- [결과보고서 (PDF)](report/결과보고서.pdf): 가설, 방법, 1·2차 결과, 야드 체류 감소 방안, 민감도, 한계
- 그림: `report/figures/` (연결선 간격 vs 체류, A/B/C별 야드 체류 감소, 방안별 효과·모선 대기 비용, 시나리오 요약)

## 핵심 결과 (2차, 반복 100회)
| 지표 | A 기존 | B 인접공유 | C 전체통합 |
|---|---|---|---|
| 평균 접안 대기(h) | 0.96 | 0.06 | 0.00 |
| 최대 터미널 가동률(%) | 142 | 133 | 129 |

- 환적 야드 체류는 연결선 접안 간격으로 거의 정해진다(상관계수 0.999). 통합(B/C)만으로는 줄지 않는다.
- 연결선 24h 앞당김 시 평균 22.1h(9.7%) 감소는 간격이 남는 컨테이너에 대한 산술적 상한이다.
- 한계: 실제 박지 대기는 모델이 2.2%만 설명한다. 절대값보다 A·B·C 상대 비교로 읽는다.

## 노트북
- `simulation.ipynb`: 1차 (A vs C)
- `simulation_v2.ipynb`: 2차 (A/B/C, 포트미스 입항 시각 반영, 모델 검증, 야드 체류 시나리오, 민감도). 실행 결과 포함. 실행하려면 `data/portmis/portmis_calls.csv`가 필요하다.
