# 부산 신항 선석 통합운영 시뮬레이션 (2025)

2025년 부산 신항 7개 터미널의 실제 접안 실적을 다시 배정해 선석 통합운영(B 인접공유, C 전체통합)이 접안 대기와 환적 야드 체류에 주는 효과를 비교한다.

## 결과 리포트
- [결과보고서 (PDF)](report/결과보고서.pdf): 가설, 방법, 1·2차 결과, 야드 체류 감소 방안, 민감도, 한계
- 그림: `report/figures/` (연결선 간격 vs 체류, A/B/C별 야드 체류 감소, 방안별 효과·모선 대기 비용, 시나리오 요약)

## 핵심 결과 (2차, 반복 100회)
| 지표 | A 기존 | B 인접공유 | C 전체통합 |
|---|---|---|---|
| 평균 접안 대기(h) | 0.96 | 0.06 | 0.00 |
| 최대 터미널 가동률(%) | 142 | 133 | 129 |

- 환적 야드 체류는 연결선 접안 간격으로 거의 정해진다(상관계수 0.999). 통합(B/C)만으로는 줄지 않는다.
- 연결선 24h 앞당김 시 평균 22.9h(10.1%) 감소는 간격이 남는 컨테이너에 대한 산술적 상한이다.
- 한계: 실제 박지 대기는 모델이 2.2%만 설명한다. 절대값보다 A·B·C 상대 비교로 읽는다.

## 노트북
- `simulation.ipynb`: 1차 (A vs C)
- `simulation_v2.ipynb`: 2차 (A/B/C, 포트미스 입항 시각 반영, 모델 검증, 야드 체류 시나리오, 민감도). 실행 결과 포함. 실행하려면 `data/portmis/portmis_calls.csv`가 필요하다.


## 3차 시뮬레이션 (KPI 목표 1·3·5·10·15·20·25·30%)

- `simulation_v3.ipynb`, `report/결과보고서_3차.pdf`
- 연결선 앞당김을 연결선(선박) 단위로 다시 계산하고 선석 시뮬레이션으로 실현 가능성을 검증했다.
- 최소 간격 24h에서 24h 앞당김은 전체 앞당김 3.1%, 선별 앞당김 5.6%다(2차 산식 상한 10.1%는 낙관적). 10%는 선별 앞당김 약 45h, 20%는 약 146h, 25%·30%는 불가(선별 최대 24.3%).
- 통합(B/C)은 체류 감소율은 같지만 앞당김의 선석 충돌(다른 선박 접안 지연)을 A보다 크게 낮춘다.


## 4차 시뮬레이션 (불확실성 구간 + 하반기 검증)

- `simulation_v4.ipynb`, `report/결과보고서_4차.pdf`
- 반복 100회와 95% 구간(연결선 단위 군집 부트스트랩)을 더했다. 선별 앞당김 48h는 10.5%(8.0~13.1%), 96h는 16.8%(12.9~20.7%)다. 구간 하한 기준으로 10%는 72~96h, 15%는 168h가 필요하다.
- 상반기로 학습하고 하반기로 검증했다. 선별 규칙은 하반기에서도 전체 앞당김의 약 2배(9.3% vs 4.7%)이고, 학습 모형으로 순위를 고도화하지는 못했다(R² 0.08).
- 후보 배의 25%만 앞당겨도 선별 효과의 73%를 얻는다.
